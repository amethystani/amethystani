The Long Game — README Poker animation

The Texas Hold’em game rules and state machine use poker-ts (MIT):
https://github.com/claudijo/poker-ts
The playing-card SVG artwork is from Block52/cards (MIT):
https://github.com/block52/cards
Their full license texts are in poker/vendor/.

the-long-game.svg is generated locally by poker/generate.mjs from actual hands dealt by poker-ts. GitHub Actions refreshes the set of hands during the daily profile update. The README SVG cycles those deals and links to the live table at https://amethystani.github.io/amethystani/poker/.
