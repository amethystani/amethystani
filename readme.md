### Better questions. Better measurements.

I study when language models—and the measurements we use to judge them—can be trusted. My work looks at conflicting scientific evidence, notation-sensitive predictions, and the blind spots in model evaluation.

I also build the benchmarks, metrics, and systems that make those questions testable.

### Research you can run

| Project | The question behind the code |
| :--- | :--- |
| **[EVIRAG-Bench](https://github.com/amethystani/evirag-bench)**<br />Scientific retrieval · Rust | What if retrieval preserved conflicting evidence instead of flattening it into one answer? |
| **[Notation Matters](https://github.com/amethystani/notation-matters)**<br />Chemistry language models | Does a model make the same prediction when the same molecule is written differently? |
| **[Palimpsest](https://github.com/amethystani/palimpsest)**<br />Translation evaluation · LIGATUR / AEGIS | How can a translation metric judge information its tokeniser has already deleted? |
| **[DeferSeg](https://github.com/amethystani/deferseg)**<br />Real-time AR · Sparse segmentation | Where should a neural model spend its compute when every frame has a deadline? |
